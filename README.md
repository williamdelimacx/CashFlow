# 💰 CashFlow API

API REST para gerenciamento financeiro desenvolvida em **.NET 8**, aplicando **Clean Architecture**, autenticação JWT e testes automatizados.

---

## 🚀 Funcionalidades

- Cadastro e consulta de despesas
- Autenticação via JWT
- Persistência com SQL Server
- Testes funcionais

---

## 🛠️ Tecnologias

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Docker
- xUnit
- Swagger

---

## 🐳 Docker
docker-compose up --build

## 🧪 Testes
dotnet test
